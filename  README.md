# Attendance Management System

## Project Overview
Spring Boot based Attendance Management System with full CI/CD pipeline using:

- Spring Boot
- Maven
- Docker
- Jenkins
- AWS ECR
- AWS EC2
- GitHub Webhooks

## APIs

### GET /attendance/status
Returns application health status.

### POST /attendance/checkin
Simulates employee attendance check-in.

## Tech Stack

- Java 21
- Spring Boot 3.5.14
- Maven
- Docker
- Jenkins
- AWS
